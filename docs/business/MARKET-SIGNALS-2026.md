## 1. What the gap was

Maintainer lacked a short, current picture of **who pays nearby** for “get my OSS/self-host thing live.” Without that, feature expansion feels blind. This note is enough to **keep building** without pretending we own category research.

## 2. Macro trends (directional)

| Trend | Signal | Orbit implication |
|-------|--------|-------------------|
| **First-party / privacy analytics** | GA4 consent fatigue; cookieless self-host (Umami, Plausible CE, Matomo) rising for indie/EU ops | **Analytics Get-live** is a real pain; Umami-class = lightest Docker/Postgres wall |
| **Commerce ownership vs Shopify default** | Agencies: Shopify for speed; Medusa when control / fees / category / B2B | Medusa buyers **already expect labor**; H1 fits; Gift detect is support — not “beat Shopify” |
| **Self-host cost illusion** | $5–12/mo VPS; setup labor often **hours → $100–500** freelance deploy gigs | Price H1 against **avoided freelance/agency day**, not against OSS bits |
| **Managed “we run it for you”** | Agencies sell managed Medusa / RUN retainers | We are **not** that company; optional one-shot standup only |
| **Tool sprawl → consolidate** | DTC analytics “unified platform” marketing | Ignore suite pitch; we sequence **one** runtime URL |

Sources are public agency/indie writeups (2025–26): Medusa-vs-Shopify agency posts, Umami/Plausible self-host comparisons, freelance VPS deploy gigs — not proprietary panels.

## 3. Payable substitutes (who already gets money)

| Substitute | Typical ask | Rough cash | Our adjacent offer |
|------------|-------------|------------|--------------------|
| Freelance VPS/Docker deploy | App + HTTPS + compose | ~$100–350 (gigs); race-to-bottom also exists | H1: first URL live once · Gift for next cuts |
| Agency Medusa / migration | Own backend · leave Shopify | Project + often RUN retainer | H1 thin slice only if hitch; else Gift sequencer |
| Hosted analytics (Plausible Cloud etc.) | Avoid ops | ~€9+/mo | Soft-no as product; Gift if they chose self-host |
| Tutorial + Discord | Free | Time tax | Gift spine + proof beats encyclopedia |

**Segment that already pays nearby:** founders who already accept VPS/host bills or agency quotes — matches Medusa study V-Segment and 146.
