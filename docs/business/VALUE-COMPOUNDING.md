## 1. Stance

```text
Capability ≠ perceived value.
Self-beta proved the host XOR can finish.
Compounding value = raise job-done certainty and cut cognitive load —
not add Ops surface area or revive CANCELLED wedges.
```

---

## 2. Value already earned (do not dilute)

| Earn when | Mechanism |
|-----------|-----------|
| Process visible | Streamed local CLI deploy |
| Result visible | Live URL + last-run evidence |
| Dashboard on the project | Open live + Open dashboard |
| Failure actionable | Troubleshoot → one recovery |

**Keep sharp:** Freelancer-shaped last mile to first public host URL — honest gates, not fake one-click past Login/OAuth.

**Reject as “enhancement”:** CDP token fill · Studio-held secrets · coach encyclopedia · AI that finishes OAuth · payment/email setup product.

---

## 3. Audience gaps (what still hurts)

### Founders (primary paid story, if any)

| Need | Failure mode |
|------|----------------|
| “Am I done?” | Outcome sentence buried |
| “What do I click now?” | Multiple equal CTAs |
| “Did it work?” | Evidence not framed for non-Ops |

**Lift:** One outcome line · one next click · one proof URL.

### OSS / pay-averse developers (Gift)

| Need | Failure mode |
|------|----------------|
| Faster than DIY | Extra ceremony vs host CLI |
| Agent/MCP fit | Assist feels second-class |
| Trust | Version/docs/demo skew |

**Lift:** Speed + dignity + truth.

## 4. UX principles (constraints)

| # | Principle | Test |
|---|-----------|------|
| U1 | One outcome visible | Surfaces answer: live URL / blocking gate |
| U2 | One primary action | Secondary collapsed until fail |
| U3 | Job words > Ops words | “Get it live” over taxonomy in General |
| U4 | Honesty is the product | Never imply Studio completes vendor login |
| U5 | Proof before polish chrome | Demo matches current release |
| U6 | Dual trunk, one identity | Gift vs H1 stories — not two products |

## 5. Ranked compounding bets

### Tier S — do first (strategy)

| Bet | Offer change |
|-----|----------------|
| **S1 Outcome contract** | Done = public URL on {host} |
| **S2 Single next-gate** | Only current human gate is loud |
| **S3 Proof bay as hero** | URL · Open live · Open dashboard · share |
| **S4 Truth sync** | Site/docs/release/demo versions aligned |
| **S5 Soft-no map** | Explicit “we don’t do X; honest path” |

### Tier A — depth one band at a time

| Bet | Note |
|-----|------|
| A1 Stranger 20-minute script | Soft proof for founders |
| A2 Fail → one recovery | Avoid recovery menus that feel like Ops |
| A3 Multi-repo “next ship” | Local portfolio cue |
| A4 MCP collaborator ritual | Assist without lying |
| A5 H1 concierge SKU | Tool as hook — optional residual |

### Tier K — kill if proposed as upgrade

More provider logos · in-app vendor coach · one-click hiding Login · CI feature-parity race · Integrations revival.

## 6. Service-shaped compounding

| Move | Role |
|------|------|
| H1 “first URL live” on their repo | Proves job-done; feeds proof |
| Written recovery cards per fail class | Scales without coach product |
| Async review of `.ship/publish.json` | Certainty without owning their account |
| OSS path always free for sequencing | Ethics + developer magnet |

Software excellence enables service; service monetizes when OSS freeloads — without claiming a DevOps company.
