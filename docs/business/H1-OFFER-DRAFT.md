## Wall (client language)

> Your project (or chosen self-hosted OSS service) reaches a **public URL you can open** on **your** host — Login and irreversible Confirms stay yours.

## What’s included

| In | Out |
|----|-----|
| Bind repo · detect · host choice · env **names** · Deploy · Open live · one recovery path | Finishing Stripe/Paddle/KYC inside Studio |
| Working session until URL or **named** blocking gate | Ongoing retainer / “we are your DevOps” |
| Short handoff notes (how you re-run / Confirm) | Building their product, catalog, or theme |
| Gift Orbit Yard for later cuts | Unlocking “premium packs” |

## Scope variants (pick one per engagement)

| Code | Wall | When |
|------|------|------|
| **H1-URL** | Marketing/app URL live | Default; attested spine |
| **H1-ANALYTICS** | Self-hosted analytics dashboard live (Umami-class) | Client already chose self-host analytics |
| **H1-COMMERCE** | Medusa admin (and/or API) URL live | Client brings Medusa repo; payments = Open vendor |

## Fee posture (courage, not cosplay)

Price against **avoided freelance deploy / half-day agency** (market: often ~$100–350 for basic VPS deploy; Medusa projects much higher) — not against “software download.”

| Tier | Intent | Rule |
|------|--------|------|
| **Anchor** | Rush / multi-service same week | Only if calendar exists |
| **Core** | One scoped wall above | Default quote |
| **Budget** | Gift self-serve + async review of *their* deploy notes | No fake “90% of core” without delivery |

Exact numbers: set in the hitch room after hearing their stuck point — silence after the number (141).

## Buyer fit

- Already pays host/VPS or has compared agency quotes  
- Can Login CLI / Confirm when asked  
- Wants **ownership**, not “make Shopify/GA nice inside Studio”

## Soft-no

Not a fit if they need Integrations theater, unlimited support, or “install every OSS app for $29.”

## Success / ritual artifact

Buyer holds: live URL · host project · `.ship` progress · one-page restart notes. Invoice describes **labor for that wall**, not a license seat.
