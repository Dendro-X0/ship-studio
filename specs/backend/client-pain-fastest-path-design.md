## 1. Client pain (their words, not ours)

| Pain (client POV) | What they do today | Why it hurts |
|-------------------|--------------------|--------------|
| “I need this **live** so I can demo / sell / onboard” | Tutorials, Discord, hire a freelancer | Time + wrong layer (vendor encyclopedias) |
| “I chose **self-host** OSS (shop, analytics, app) but setup is a maze” | Copy-paste compose · env folklore | No one sequence; fail is opaque |
| “Third-party Integrations feel impossible” | Vendor dashboards / agencies | Walled gardens — Studio must not claim to finish these |
| “I don’t need every feature — I need **my** job done” | Fear of buying a suite | Confirms: never sell packs; sell walls |

**Core job (one sentence):**

> Get **my** chosen self-hosted thing to a **public URL I can open**, with the fewest confusing steps and one honest place I’m stuck.

Fast / convenient / effective **from their POV** = time-to-wall, one loud next action, recoverable fail — not feature count.

## 2. What we optimize (metrics)

| Lever | Client-facing meaning | Instrument |
|-------|----------------------|------------|
| **Fast** | Minutes to URL or named gate (not days of search) | Stranger 20-min script · Soft-L3 |
| **Convenient** | One spine; Login/Confirm only where vendor owns | Founder F1–F5 · MCP pause/resume |
| **Effective** | Observable done (URL / admin) they keep | Proof bay · ritual artifact (146 V-Ritual) |

**Do not optimize:** number of OSS logos, Integrations completion rate, $29 conversion.

## 3. Offer architecture (locked)

```text
Gift:     Orbit Yard sequences Get-live for their repo / owned OSS runtime
Residual: Scarce H1 — “this wall, once, on your host” (labor)

```

| Client asks | We answer |

| Do you finish Stripe for me? | No — Open vendor; we sequence deploy + env names |

Value equation (141): raise **likelihood** (proof) and cut **effort** (spine); price H1 against **avoided agency day**.
