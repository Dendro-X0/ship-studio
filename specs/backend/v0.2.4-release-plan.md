## Why this tag

| Problem | v0.2.4 answer |
|---------|----------------|
| v0.2.3 is still **Ship Studio**-era branding on GitHub Releases | Orbit Yard name · `orbityard` CLI · `yard_*` MCP in the artifact set |
| Post-freeze commits on `main` are not in a release | Bundle finishability, host auth, Netlify, butler, MCP G1–G4, `yard_setup` |
| Site download still points at old releases tree | Point `PUBLIC_DOWNLOAD_URL` at `…/releases/tag/v0.2.4` after publish |

## In scope (must ship)

### A. Land working tree

1. Commit uncommitted `yard_setup` band (mcp · publish · skill · specs · handoff).  
2. Bump workspace version **0.2.3 → 0.2.4** (`Cargo.toml` workspace, Desktop `Cargo.toml` / `tauri.conf*` if versioned, any package.json that pins product version).  
3. Move CHANGELOG **Unreleased** → **## [0.2.4] — 2026-10-04** (date of cut); leave a fresh empty Unreleased. Add `yard_setup` under Added if not already listed.

### B. Verify (cheap gates before tag)

| Layer | Command / check |
|-------|------------------|
| L1 | `cargo test -p orbityard --locked` |
| L1b | `cargo build -p orbityard --release` · `orbityard --help` · `orbityard doctor --project .` |
| L2 | `pnpm desktop:release` (portable pair) · optional `--installer` for NSIS |
| L2b | Smoke: bind Harbor or this repo → Publish shows Orbit Yard / Public → Deploy toast honesty |
| L2c | MCP: tools list includes `yard_setup` + `yard_*` (not only legacy names) |

CI on push to `main` is the remote L1 mirror (`.github/workflows/ci.yml`).

### C. Publish GitHub Release

Artifacts (Windows primary, same as prior cuts):

| Asset | Source |
|-------|--------|
| `orbityard.exe` | `target/release/orbityard.exe` |
| `orbit-yard-desktop.exe` | staged portable from `scripts/stage-desktop.sh` |
| NSIS setup (optional but preferred) | `pnpm desktop:release` / stage with `--installer` |

Release notes: short “Orbit Yard rebrand + MCP minutes setup + Client finishability” — link CHANGELOG.  
Tag: `v0.2.4` on the version-bump commit. Prefer `gh release create` from a human TTY (bridge never auto-creates).

### D. Site pointer (same day, thin)

1. Set Netlify env `PUBLIC_DOWNLOAD_URL=https://github.com/Dendro-X0/ship-studio/releases/tag/v0.2.4` (or equivalent).  
2. Redeploy website if needed so Download CTA hits the new tag.  
3. Update `docs/CURRENT.md` + handoff: OSS ready at **v0.2.4**; idle again.
