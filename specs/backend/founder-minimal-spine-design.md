## Strategy (locked)

Build valuable **services and products** for solo founders, indie multi-repo operators, and small–medium teams by making Orbit Yard a **self-contained local deployment stack**: rigorous end-to-end execution through **minimal steps**.

| Phrase | Honest meaning | Forbidden meaning |
|--------|----------------|-------------------|
| Self-contained | Local kernel + one Publish spine + host CLI automation + honest human gates — operator rarely leaves except Login / irreversible Confirm | Orbit owns hosting, CI runners, or payments |
| Rigorous E2E | Script what is scriptable; pause where the vendor is authority; Verify layers stay honest | Fake greens / one-click that hides OAuth |
| Minimal steps | One loud next action; secondaries collapse; Advanced stays Advanced | Fewer logos by deleting Tier A hosts |

**Offer sentence (unchanged from host XOR):**

> First public host URL — visible process, visible result, honest gates.

## Audiences → jobs

| Audience | Job | Minimal-spine implication |
|----------|-----|---------------------------|
| **Solo founder** | Get live to demo / sell / onboard | Default path = **Get live**; stores/sign optional |
| **Indie / multi-repo** | Same ritual across folders | Local `.ship/` + CLI/MCP; no cloud hub required |
| **SMB (2–15)** | Ship without a dedicated ops hire | Shared sequence + evidence; not seats/SaaS suite |

They hire **certainty**, not an Ops category label. Category mimicry of GitHub Actions / Vercel / Fastlane remains **CANCELLED** as company GTM ([commercial-product-failed](./commercial-product-failed-design.md)).

## The five-step spine (General)

Done = public URL on the chosen host (or a **named** blocking gate).

| # | Step | Operator action | Studio action |
|---|------|-----------------|---------------|
| 1 | Open project | Bind folder | Detect layout |
| 2 | Choose host | Card / detect | Affinity + auth-check |
| 3 | Login once | Vendor OAuth if needed | Login CLI / Sign in (web) |
| 4 | Env + Deploy | Put / Import env → Deploy | Stream hostdeploy · evidence |
| 5 | Proof | Open live · Confirm | URL bay · one recovery on fail |

Sign, GitHub release, store submit, Integrations = **later / Advanced** unless the chosen workflow explicitly includes them.
