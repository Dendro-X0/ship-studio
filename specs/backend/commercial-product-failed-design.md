## Verdict

Orbit Yard **did not meet the goals of a commercial product.**

| Attempted wedge | Why it is not a business |
|-----------------|--------------------------|
| Help users complete Polar/Paddle/Stripe | Walled gardens; official UI is the setup; Polar succeeded **without** Studio |
| Sell Solo via Orbit-owned checkout | Requires Orbit billing/cloud we do not have; Paddle path was unusable motivation |
| Pivot to **ops and deploy** as the paid story | That category is already **GitHub Actions / host dashboards / Fastlane / release-please / Vercel–Netlify–Cloudflare** |

Commercializing the ops/deploy pivot means **competing with existing DevOps products** with no owned runtime, no owned payments, and no lock-in we can honestly sell. That is not a differentiated company. Narrower ops/deploy makes the **tool more viable as personal/OSS software**; it does **not** create a market.

## What remains (non-commercial)

- A **local sequencer** the maintainer can keep using on their repos  
- GitHub Releases as distribution (v0.2.4)  
- MCP pause for **this** deploy/sign gate — not a SaaS SKU  

**Do not** invent a third paid wedge (AI DevOps, “better CI”, “integration platform 2”). Those collide with the same vendors or the same failure.

## Never-say

- Orbit is ready to charge because the Client is honest  
- Ops/deploy pivot = go-to-market  
- Compete with GitHub/Vercel on deploy as the path to revenue  

Website `/pricing` is leftover, not a sales motion.
